# Cross-machine handoffs

This directory keeps the minimal state needed to resume opend-ai work from another machine, terminal, or AI session.

`CURRENT.md` should answer five questions quickly:

1. What state is `main`/the active branch in?
2. What was just learned or changed?
3. What evidence or tests support that?
4. What is still unresolved?
5. What should happen next?

Detailed evidence belongs in the relevant `docs/evaluations/`, `docs/investigations/`, `docs/decisions/`, or `docs/plans/` path. Link to those files rather than copying large reports into the handoff.

Update `CURRENT.md` after substantive work so that repository state, not a particular chat transcript or local machine, is the continuity mechanism.
